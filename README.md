# BalokKosong

Game puzzle Flutter untuk Android dan iOS.

## Informasi build

- Versi aplikasi: lihat `version:` pada `flutter/pubspec.yaml`
- Perubahan per versi: [CHANGELOG.md](CHANGELOG.md)
- Riwayat setiap build: [docs/BUILD_HISTORY.md](docs/BUILD_HISTORY.md)
- Cara menyiapkan dan merilis build: [docs/BUILD_MANAGEMENT.md](docs/BUILD_MANAGEMENT.md)

GitHub adalah sumber utama kode dan riwayat build. App Store Connect dan Google
Play Console digunakan untuk pengujian serta distribusi file yang sudah tercatat
di GitHub.
